Fake News Detection System

Multi-Modal News Veracity Analysis using NLP and Machine Learning.

Analyze news authenticity across Direct Text, PDF & Word Documents, or live Website Links. NLP

5,000 max features capturing unigram and bigram frequency-inverse weights.

Logistic Regression

Linear classification model estimating probability thresholds for text features.

SVM

Linear Support Vector Machine maximizing separation margins in sparse vector space.

Ensemble classification model aggregating votes across randomized decision trees.
